# Two Crossings: the family archive

This is the research archive behind *Two Crossings: The Andersons and the Ealicks*, a family history John Anderson made in 2026 for his parents, Jim and Cathy Anderson. It holds the records, photographs, transcriptions and working notes behind the book.

The files are locked. **The password is printed in the book.**

## How to open it

1. Open **Releases** on the right of this page and download the four files ending in `-LOCKED.zip`. Each part opens on its own, so start with part 1 if you only want one.
   - Part 1, book and notes: the book itself (PDF), the family tables, the notes and the text. Start here.
   - Part 2, records: the document images and transcriptions.
   - Part 3, pictures: the photographs and pictures used in the book.
   - Part 4, workshop: the book's build files and some original downloads.
2. Double-click a downloaded file and type the password from the book.
3. Inside is a second zip file. Double-click it to open the folder.
4. Read `README.md` first.

These are ordinary zip files and should open on any computer. If one does not, the free program 7-Zip opens them.
